# Locally hosted fonts

These fonts are bundled with the app so Next.js can build and run without
contacting Google Fonts. They come from the [Google Fonts repository](https://github.com/google/fonts)
and retain their individual SIL Open Font License files in each directory.

- `inter/` — Inter variable font, body text
- `barlowcondensed/` — Barlow Condensed SemiBold and Bold, display headings
- `ibmplexmono/` — IBM Plex Mono Regular, Medium and SemiBold, data labels
- `notosansethiopic/` — Noto Sans Ethiopic variable font, Amharic text
